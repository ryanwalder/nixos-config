---
name: Assume commands have been run
description: Never suggest the user hasn't run a command you told them to run
type: feedback
---

Always assume the user has run any commands or rebuilds you instructed them to run.

**Why:** User finds it condescending and annoying to be asked if they ran the command.

**How to apply:** If something isn't working after a change, diagnose the problem on its merits — never suggest "maybe you haven't rebuilt/restarted/run the command yet" as a hypothesis.
