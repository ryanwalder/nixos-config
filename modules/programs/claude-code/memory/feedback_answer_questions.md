name: Answer questions, don't edit
description: When user asks a question, answer it — do not edit files, implement, or take action until they ask
type: feedback
---

When the user asks a question, answer it and wait. Do not edit files, do not start implementing, do not "go ahead and fix it while I'm here." A question is a request for information, not a license to act.

**Why:** User only has plan-mode and accept-edit-mode available. They use plan mode specifically to stop me from editing files when they're just asking a question — because I have a habit of treating questions as implicit go-aheads to start changing things. That habit is the actual problem; plan mode is their workaround.

**How to apply:** "Why X?" / "What is X?" / "What does X do?" / "How does X work?" → text answer only. Do not propose edits, do not enter implementation. Wait for an explicit instruction like "fix it", "change it", "do it" before touching files.
